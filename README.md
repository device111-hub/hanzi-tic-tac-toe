# 汉字井字棋

一款双人手写汉字井字棋。棋盘每格显示一个拼音，玩家需要用鼠标、触控笔或手指写出对应汉字；写对后占领该格，率先连成横、竖或斜线三格者获胜。

## 功能

- 3×3 汉字棋盘，支持鼠标、触控笔和手指书写
- 使用本地字形匹配进行识别，书写内容不会上传
- 写错不换人，可清空重写；连续失败后显示淡色字形提示
- 每个新回合随机更换 9 个题目，同一局内不重复
- 内置 45 个常用汉字题库
- 自动判定胜负、交换先手并保存比分
- 游戏棋盘保留拼音和汉字，其他界面说明使用俄语
- 完全静态，无需后端服务

## 使用方法

直接用浏览器打开 `index.html`。

也可以在本目录启动静态服务器：

```bash
python -m http.server 8088
```

然后访问 `http://localhost:8088/`。

## 文件

- `index.html`：完整游戏，包含页面、样式和手写识别逻辑

## 浏览器要求

建议使用最新版 Chrome、Edge、Safari 或 Firefox，并启用 JavaScript。
